# 共享术语（研究接口约定）

| 术语 | 本Skill采用的意义 | 来源/边界 |
|---|---|---|
| n,m,N | 输入维数、输出维数、2^n真值表长度 | D接口，避免原书不同记号混淆 |
| 坐标/分量 | 坐标是F_j；分量是任意非零b的b·F | E，必须检查所有分量 |
| ANF/代数次数 | F₂平方自由展开及最高非零单项式次数 | B13；实现约定零函数次数−1 |
| RM(r,n) | 次数≤r函数的真值表线性码 | B13，码长2^n |
| Walsh | 对(-1)^f作未归一化Hadamard变换 | B14现代记法，整数求和 |
| NL / 第r阶NL | 到RM1 / RMr的最小Hamming距离 | B/D/E；启发式不是精确值 |
| bent/plateaued | 全谱常模 / 非零谱只有一种幅度 | B14/E；bent不平衡 |
| 二次极化 | f(x+y)+f(x)+f(y)+f(0) | B15；次数≤2才是所需双线性型 |
| CI/韧性 | 低重量非零频率谱为零 / 再加平衡 | E；常函数CI和韧性要分开 |
| AI | f或f+1的非零湮灭子最小次数 | E；不等于代数次数 |
| DDT/δ | 非零方向差分输出计数表及其最大值 | E；有序x，计数偶数 |
| APN/PN/AB | 方形二元δ2 / 所有非零导数均匀 / 奇维方形特定谱性质 | E；不能互换标签 |
| EA | B F(Ax+s)+Lx+c，A/B可逆 | E；L可破坏置换性 |
| CCZ | 图像集合在可逆仿射作用下等价 | E参考；当前未实现分类 |
| 函数生成码 | 1、输入坐标、输出坐标生成的完整长度码 | D；使用NL桥梁先检查满秩 |
| weight/distance分布 | 相对零点重量 / 码字对距离的归一化统计 | B5；非线性码须区别 |
| MacWilliams | 二元线性码枚举器的精确变换 | B5；可行枚举器不证明存在 |
| MS | 有限域中的循环变换多项式表示 | B8；不是Walsh实谱 |
| 自对偶/形式自对偶/函数对偶 | C=C⊥ / 分布变换不变 / bent谱符号定义的函数 | B19/B14，三种不同概念 |
| t-design/OA | 子集包含次数均匀 / 任意t列投影均匀 | B21；先确定方案和底集合 |
| 精确有限验证/一般证明 | 检查给定有限对象 / 证明所有满足条件参数 | 不以有限例代替族结论 |

候选的详细阅读位置见candidates/glossary.md；扩展定义的primary来源见resources/proof_ledger.md。引用历史资料不表示完成当前文献查新。
