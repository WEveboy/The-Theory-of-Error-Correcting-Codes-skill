## 1. 结构

**一句话主旨：** 用有限域、线性代数、字符变换与组合结构，构造具有指定距离性质的码，并研究其重量分布、界和译码。

原书骨架可以归为六个相互依赖的部分：

1. 第 1—2 章建立线性/非线性码、距离、Hadamard 矩阵与设计的基本语言。
2. 第 3—4 章建立有限域计算工具，第 5—6 章建立对偶、重量分布及组合约束。
3. 第 7—12 章研究循环、BCH、RS、MDS、alternant/Goppa 等代数构造及译码。
4. 第 13—15 章以布尔函数解释 RM 码，以变换及二次型解释陪集、bent 和 Kerdock 等构造。
5. 第 16—20 章研究 QR、组合构造、自对偶与特殊优良码；第 17 章给出一般距离界。
6. 第 21 章用关联方案统一若干距离分布、秩分布和线性规划界。

这是一条“基本对象 → 代数与变换 → 结构化构造 → 参数计算与界”的论证路线。用户目标下的阅读顺序可以改变，原书的历史与论证结构不能被改写成一本现代 S 盒教材。

作者的核心问题是：给定长度和允许的距离，怎样构造更大的码、证明参数并有效译码？本项目增加的研究问题是：哪些码结构能够反向指导函数构造、谱控制与不可能性证明？后一个问题属于应用转化。

## 2. 解释

| 原书术语 | 原书用法及本项目约定 |
|---|---|
| 线性码 | 有限域上向量空间的子空间；维数必须由秩确定 |
| 非线性码 | 不要求为子空间的向量集合；不能默认用线性对偶解释 |
| 对偶码 | 与所有码字正交的向量构成的子空间 |
| 重量/距离分布 | 前者相对零向量计数，后者平均计数码字间距离；一般非线性码须区分 |
| RM(r,n) | 本项目用 n 表示变量数：所有次数不超过 r 的布尔函数真值表，长度 N=2^n |
| 一阶 RM 陪集 | f+RM(1,n)，由向 f 添加全部仿射函数得到 |
| Hadamard 变换 | 第 14 章对符号向量 (-1)^f 的实数变换，本项目写为 Walsh 谱 |
| bent | 所有 Walsh 系数绝对值均为 2^(n/2)；n 必须为偶数 |
| symplectic form | 特征 2 下的交错双线性型，可由对称零对角矩阵表示 |
| MS 多项式 | 有限域中的循环变换表示；不是实数 Walsh 谱 |
| 形式自对偶 | 分布在 MacWilliams 变换下不变，不能直接替换成 C=C⊥ |

核心命题及依据：

1. 线性结构让校验方程、生成矩阵和对偶互相转换（第 1 章）。
2. 有限域支持由整数标签到代数对象的可计算表示，但表示选择须记录（第 3—4 章）。
3. 字符正交性把一个线性码的重量枚举器转为对偶的枚举器（第 5 章定理 1）。
4. 循环结构可用理想、零点与 MS 表示互相描述（第 7—8 章）。
5. RM 的单项式描述把代数次数变成码空间层级；递归分解给出参数与构造（第 13 章）。
6. 一阶 RM 陪集的重量由 Hadamard 谱确定；最大谱幅对应最近仿射函数（第 14 章定理 1）。
7. Parseval 约束给出 bent 的极值解释；直接和及特定双线性型给出构造（第 14 章定理 6、10、12）。
8. 二阶 RM 陪集对应交错型，秩决定陪集重量分布（第 15 章定理 1、5）。
9. 控制两两型之和的秩，可以控制相应陪集并集的距离（第 15 章 §5）。
10. 距离/秩分布满足非负变换约束，可用于排除不可能参数（第 17、21 章）。

核心证明链：布尔函数平方自由展开 → RM 单项式基 → 仿射陪集 → 字符求和与距离等式 → Parseval 极值 → 二次型标准形与根空间 → 两两差的秩 → 函数族/码族距离 → 关联方案界。

## 3. 批判与边界

**时代边界。** 本书的历史记录、参数表和“尚未解决”标签反映当时状态。现代 APN、向量谱、EA/CCZ 分类及代数免疫等内容需要后续文献；不能把现代术语回填成原书明确陈述的定理。

**目标边界。** 书中主要优化码长、距离和规模。这些指标不能单独担保函数满足置换性、差分均匀性、代数免疫或具体系统的安全要求。没有证据支持对作者个人背景或立场作额外推测。

**证明边界。** 原书部分结果明确省略证明，例如第 19 章开头定理 1。后续卡片必须标明“书中证明”“重建证明”“引文结果”“有限验证”；不能给所有内容统一贴上“已证”。

**文本边界。** OCR 会丢失指数、求和符号和矩阵。p.430、p.441 已回看扫描页。p.430 习题 20 的印刷公式存在可复现反例，见精读稿与 `validation.json`；暂不作为有效构造编译。是否有官方勘误仍待查。

**最强反对意见。** 仅凭一本 1977 年编码教材不足以覆盖现代函数科研。这一意见成立。因此方案分为“原书可追溯基础”“自行证明的桥梁”“有独立来源的现代扩展”，分别审计，保持每个结论的适用范围。
