# 扩展研究地图：按可运行程度分层

此表用于接受用户“尽可能扩展有潜力内容”的任务，不把参考主题算作已实现算法。每项研究先规定输入、命题及需要的证明/实验，任何新颖性结论另做原始论文查新。

## A：已有精确工具的研究入口

| 方向 | 现在可运行的工作 | 后续研究问题与条件 |
|---|---|---|
| RM/ANF | 全分量次数、谱、距RM1；n≤4精确距RM2 | RM陪集分类、高阶逼近；一般r的精确距离未实现 |
| bent/plateaued | 标量常模/单一非零谱幅检查，MM/二次构造 | 对偶、谱支撑、间接和/其他二次构造须附证明 |
| 向量bent | 全非零分量谱与维数/秩检查 | 构造高维满秩型空间，m≤n/2，不能要求方形置换 |
| APN/差分 | 全DDT、δ、最坏方向，Gold构造与幂搜索 | 扰动/拼接族先证明全参数核条件 |
| 高非线性S盒 | 全分量NL、次数、δ、置换/平衡、置换BCT、DLCT | 多目标搜索，不能仅用坐标NL评分或声称安全 |
| 相关免疫/韧性 | CI/韧性阶、低重量Walsh支持 | 流密码适用条件、代数/快速相关攻击需额外研究 |
| 代数免疫 | n≤6精确AI和湮灭子 | 高维结构化构造与高阶抗性，次数不能替代AI |
| 差分传播 | 自相关、线性结构、二次导数秩、坐标SAC、全分量PC阶数 | GAC及其他PC变种须单独定义；不默认所有标签同义 |
| 少重量码 | C_F秩门、有限枚举、对偶变换 | 逆向指定谱型、推导参数化重量分布；枚举器不证明存在 |
| 等价去重 | 给定EA/CCZ图变换证书、完整图谱/DDT不变量预筛 | 自同构群、规范形、未知CCZ变换搜索尚需专用算法 |
| 有限域构造 | 多项式、绝对迹、给定基的对偶基及坐标恢复 | 域模型固定；参数族定理和符号解析另做 |
| 实验归档 | 构造、指标、可选S-box结果及SHA256清单 | 检查manifest与全部哈希，不替代全族证明 |
| 设计/OA | 给定支持集t-design、投影均匀性检查 | 从函数纤维、码重量层构造；定理条件必须完整 |
| 低相关序列 | 显式序列的周期/xor自互相关 | 迹序列族、互相关分布、多用户通信；群作用分别定义 |

## C：需要独立现代来源与专门实现的扩展

- AB、CCZ与图像码分类：可用现有全谱/DDT产生数值证据；AB标签及CCZ不等价必须核对定义与定理，当前没有全分类器。
- 非二元/p元函数、一般矩形m>n：当前核心不支持；必须重新定义字符、平衡和差分，不能硬塞二元接口。
- 隐藏加法、一般置换多项式族及广义非置换boomerang表：仍需专门实现。经典置换BCT和二元DLCT已实现，DLCT使用AC/2计数偏差，不混用归一化。
- 密码实现复杂度、门电路/掩码、侧信道指标：现有ANF只能提供代数材料，不能据其次数判定侧信道安全。
- 秘密共享、认证码、哈希、组合设计和通信应用：从少重量码/支持集建立桥梁后，按具体应用的访问结构、泄漏模型或相关界另证；不能自动给安全保证。
- 高维启发式/约束求解：SAT/SMT/MILP可成为搜索器后端，但必须保留可检查见证、搜索空间和不可行证书，当前无这类依赖。

## 推荐研究输出格式

每次给出：问题与目标指标 → 适用定理/假设 → 构造与输入 → 精确有限结果及见证 → 参数族证明或未决义务 → 等价/文献状态 → 下一步。不同目标可以组合，但应按阶段调用能力卡，不能用一个总分掩盖失败性质。

第一试点：二次型空间→向量bent→少重量码→支持集检查。
第二试点：Gold/幂候选→全DDT/谱→EA证书预筛→参数族证明。
第三试点：谱约束→韧性/AI/高阶距离→应用条件核对。
